📥 Import File — Excel / CSV

Bulk-load students into the Main Entry Sheet. Course cells accept “CODE” or “CODE — Name”; wrong-column codes are rejected with a row-wise report.

⬆ Upload file

⬇ Excel Format ⬇ Sample File
  1. Download the Excel Format (or Sample) first.
  2. Fill rows from row 2 — headers: Enrollment No, Student Name*, Faculty No., Mobile, Semester, VAC V / VOC V / VAC VI / VOC VI (Course Code), Counselling Date (DD-MM-YYYY), Status, Remarks.
  3. Upload the saved file. Valid rows import; errors are listed with row numbers. Duplicate Enrollment Nos are rejected.
  4. Course sheets (VAC V / VOC V / VAC VI / VOC VI) separate automatically.
